## 五个写在条款里、会影响实际使用的限制

1. **无广告档也不是完全没有广告。** 所有 Disney+ 套餐都会在部分直播与线性内容中插播广告。没有分级内容的直播体育、新闻，以及随内容播放的广告，可能出现成人向题材、产品与服务推广。
2. **Hulu 的内容在 Disney+ 里只有一部分。** Disney+ 内的 Hulu hub 是精选，完整库仍然只在 Hulu 应用里。HBO 内容同理，在 Hulu 应用内能看到一部分，完整库要进 HBO Max 应用。
3. **下载限制因捆绑服务而异。** 不是买了 Premium 就能在三个服务里随便下载，具体规则要看 Disney+ 帮助中心。
4. **6 个月促销价的退出机制。** 期内取消在期末生效，期内不能转成其他优惠价。
5. **学生价是"持续有效"而不是"一次认证"。** $6.49/月的前提是在读身份一直通过 SheerID 验证，身份失效就回到 $12.99/月或当时的常规价。这个价格只对美国 18 岁以上、就读美国大学或可授予学位/证书的认证院校的学生开放，ESPN 订阅者和通过 HBO Max 计费的捆绑用户不能领。

## 为体育多付 $14 值不值：ESPN Unlimited 和 Select 差在哪

两个 ESPN 档位的差别是频道数量。

ESPN Select 只包含 ESPN+，以及精选的 ESPN 节目，覆盖顶级足球、PGA TOUR、NHL、大学体育等赛事。ESPN Unlimited 包含全部 ESPN 网络：ESPN、ESPN2、ESPNU、SEC Network、ACC Network、ESPNEWS、ESPN Deportes、ESPN on ABC，加上 ESPN+、SEC Network+、ACC Network Extra，还有 NFL Network。

从 ESPN Select 捆绑 $21.99 升到 ESPN Unlimited 捆绑 $35.99，每月多 $14。判断标准很简单：你要看的比赛在 ESPN 主频道或 NFL Network 上，就选 Unlimited；只看 ESPN+ 里的足球、高尔夫、大学赛事，Select 就够。
